## PDF Automation

A collection of Python scripts for creating, processing, and extracting data from PDF documents.

- `00create_pdf.py` — Creates a formatted PDF document with text and images using FPDF.
- `01create_pdf_from_excel.py` — Reads Excel data with Pandas and generates a PDF document for each row.
- `02extract_text_from_pdf.py` — Extracts text content from PDF documents for further processing.
- `03extract_tables_from_pdf.py` — Extracts tabular data from PDF documents and processes it into structured data.
