## APIs

- `00get_news_from_open_news.py` — Retrieves popular news articles by keyword and country using the NewsAPI.
- `01weather_forecast_api.py` — Retrieves weather forecast data from OpenWeatherMap and saves it to a CSV file.
- `02create_your_own_rest_api.py` — Creates a Flask REST API that provides currency exchange rates.
- `03grammar_correction.py` — Uses the LanguageTool API to detect grammar errors and suggest corrections.
