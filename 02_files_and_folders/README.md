## Files & Folders Automation

- `00add_prefix_to_all_filenames_in_folder.py` — Adds a prefix to all filenames in a folder.
- `01rename_all_files_based_on_folder.py` — Renames files based on the name of their containing folder.
- `02add_date_created_to_filenames.py` — Adds the file creation date to filenames.
- `03change_file_extensions.py` — Changes the file extensions of files in a folder.
- `04create_empty_files_and_delete_forever.py` — Creates empty files and permanently deletes files.
- `05zip_archive.py` — Creates ZIP archives from files and folders.
- `06search_file_in_computer.py` — Searches the computer for files matching specified criteria.
- `07delete_files_forever.py` — Permanently deletes selected files.
